# Midjourney Factory v0.1.0

First public open-source release of Midjourney Factory.

## Highlights

- Local-first workflow for Midjourney / Niji prompt generation, review,
  Discord automation, and image curation
- Modular pipeline across `Architect`, `Commander`, `Factory`, and `Curator`
- Human-in-the-loop approval flow before prompt execution
- Desktop shell support for macOS via Electron
- Test coverage across the main modules
- Initial open-source documentation, contribution guide, security policy, and
  code of conduct

## What This Release Is For

- Publishing the first public OSS version of the project
- Giving contributors a runnable local baseline
- Establishing the repository structure for future iteration and releases

## Known Scope

- Early-stage release intended for self-hosted local use
- No hosted demo service
- Setup still assumes familiarity with local creative tooling, Discord, and
  environment configuration

## Next Priorities

- Improve onboarding and setup reliability
- Expand regression coverage
- Add more contributor-facing examples and docs
- Harden local credential and browser-state handling
