# 30-Second Demo Video Script

## Goal

Show Midjourney Factory as a complete local-first workflow:

`LLM draft -> human review -> Discord execution -> local curation`

## Version

- Recommended tag: `v0.1.0`
- Repository: `https://github.com/moxistudio/midjourney-factory`

## Shot List

### 0s-4s

Visual:
- Open the Commander dashboard landing view
- Keep the top navigation and title visible

Voiceover:
- "This is Midjourney Factory, a local-first workflow for Midjourney and Niji."

On-screen caption:
- `Local-first creative pipeline`

### 4s-9s

Visual:
- Click into `Architect`
- Show topic input and draft generation controls

Voiceover:
- "It starts by generating structured prompt drafts with an LLM."

On-screen caption:
- `1. Generate prompt drafts`

### 9s-14s

Visual:
- Show draft review / approval area in Commander
- Highlight approval flow

Voiceover:
- "Instead of blind automation, every batch goes through human review first."

On-screen caption:
- `2. Review before execution`

### 14s-20s

Visual:
- Switch to `Factory`
- Show queue / controls / logs

Voiceover:
- "Approved prompts are sent to Discord through the Factory module."

On-screen caption:
- `3. Dispatch to Discord`

### 20s-26s

Visual:
- Switch to `Curator`
- Show keep / discard workflow on generated images

Voiceover:
- "Then you curate the generated images locally and keep only the best outputs."

On-screen caption:
- `4. Curate results locally`

### 26s-30s

Visual:
- End on the repo page or return to the full workflow view

Voiceover:
- "Midjourney Factory turns scattered prompting into a reusable creative pipeline."

On-screen caption:
- `Open source now on GitHub`

## Recording Tips

- Record at 1440p or 1080p, 16:9
- Keep each shot under 5-6 seconds
- Use zoom or crop instead of fast cursor movement
- Prefer captions even if you also use voiceover
- If Discord content is sensitive, blur message history and channel names
