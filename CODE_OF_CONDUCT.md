# Code of Conduct

This project aims to be welcoming, practical, and respectful.

## Expected Behavior

- Be respectful and constructive.
- Focus feedback on the code, docs, or workflow instead of the person.
- Assume good intent and ask clarifying questions before escalating.
- Share reproduction steps, logs, and context when reporting bugs.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks
- Doxxing or publishing private credentials, session state, or user assets
- Spam, trolling, or intentionally disruptive behavior
- Public disclosure of exploitable security issues before maintainers can assess
  them

## Enforcement

Maintainers may edit, hide, or remove content that violates these guidelines
and may limit participation for repeated abuse.
